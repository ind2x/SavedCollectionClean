savedpoststree는 Instagram의 저장한 게시물을
내 기기에서 정리하는 브라우저 확장 프로그램입니다.
아래 순서대로 설치한 후 사용할 수 있습니다.

사용할 브라우저를 선택하세요.

스토어 등록 전 베타로, 압축을 풀어 직접 설치합니다.
Chrome·Edge PC용이며 휴대폰 Instagram 앱은 지원하지 않습니다.

  1. 01

    ZIP 다운로드와 압축 해제

    설치 파일을 내려받고 내 컴퓨터에 압축을 해제합니다.

    ZIP 다운로드
  2. 02

    확장 관리 페이지 열기

    아래 주소를 복사해 브라우저 주소창에 직접 붙여넣으세요.

    chrome://extensions
  3. 03

    개발자 모드에서 폴더 불러오기

    개발자 모드를 켜고, ‘압축해제된 확장 프로그램을 로드합니다’를 눌러 savedpoststree-extension 폴더를 선택하세요.

  4. 04

    Instagram에서 로그인 후 실행

    Instagram 웹에서 직접 로그인하고 표시 언어를 한국어로 맞춥니다. 해당 탭에서 확장 아이콘을 눌러 사용자 이름과 정리할 컬렉션을 확인하세요.

로그인은 Instagram에서만.

비밀번호와 쿠키를 읽지 않습니다.

작업 기록은 창 안에만 남습니다.

필요할 때 내 기기로 내려받으세요.

전체 저장 해제는 다른 컬렉션의 중복 저장에도 영향을 줍니다. 실행 전 대상과 확인 문구를 반드시 확인하세요.

개인정보 처리 안내

확장 프로그램은 사용자가 확장 아이콘을 눌렀을 때 허용한 Instagram 탭에서만 화면을 읽고 클릭합니다. 사용자 이름, 컬렉션 이름과 처리 결과는 실행 중인 확장 창의 메모리에만 두며, 비밀번호·쿠키·로그인 토큰을 읽거나 우리 서버로 전송하지 않습니다.

확장에 외부 통신·쿠키·브라우저 저장소 권한을 넣지 않았습니다. 기록을 내려받으면 해당 파일은 사용자의 기기에 저장됩니다. 창을 닫으면 내려받지 않은 기록은 사라집니다.

이 안내 사이트에는 분석 도구·광고·추적용 쿠키를 넣지 않았습니다. 다만 사이트 및 파일 제공에 필요한 일반 접속 정보는 호스팅 제공자나 GitHub가 처리할 수 있습니다. Instagram 이용 중 발생하는 통신은 Instagram의 정책에 따릅니다.

베타 확장은 모의 화면에서 동작을 검증했습니다. 실제 Instagram UI 변경·로딩 실패·제한 안내가 나타나면 중단합니다. 제한을 우회하거나 해제하는 기능은 없습니다. 문의 및 소스 확인은 GitHub에서 할 수 있습니다.
